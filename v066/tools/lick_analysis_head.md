# 재즈 릭 분석과 v0.66.3~0.66.4 보완

작성 2026-11-14 · 대상: EzImprovJazz 엔진의 「릭 사전」(한 마디 릭)과 「셀」(4음)

## 1. 결론

- 고치기 전에는 릭 사전이 **사실상 쓰이지 않고 있었다.** 32마디에 0.1~0.2번, 그것도 대부분 `chA` 하나였다. 사전이 작아서가 아니라 릭이 들어갈 수 있는 자리가 너무 좁았다.
- 지금은 32마디에 **1.0번(단계 3) ~ 1.5번(단계 4·5)** 나오고, 88개 가운데 60개 안팎이 실제로 쓰인다. 같은 릭이 한 솔로 안에서 되풀이되는 일은 드물다(4코러스 솔로 열 개에 한두 번).
- 새로 넣은 릭 80개는 전부 재즈 교육에서 공통으로 가르치는 공식이다. 특정 녹음의 전사나 곡의 선율은 없다.
- 새 릭의 4음 조각 266개 가운데 66개(25%)가 엔진에 들어 있는 WJD 실측 셀(4명 이상의 솔로에 공통으로 나온 음형)과 정확히 같다. 기존 릭은 14%였다.
- 수치는 모두 자동 측정이다. 소리로 듣고 판단한 것이 아니므로, 많다/적다는 설정 화면의 「릭 빈도」로 직접 맞춰 보시기를 권한다.

## 2. 고치기 전 — 왜 릭이 안 나왔나

14곡 × 6시드 × 4코러스(336코러스), 관악 기준.

| | 릭 수 / 32마디 | 실제로 쓰인 릭 |
|---|---|---|
| v0.66.2 단계 3 / 4 / 5 | 0.11 / 0.16 / 0.18 | 8개 중 5~7개 |
| v0.66.4 단계 3 / 4 / 5 | 1.02 / 1.50 / 1.50 | 88개 중 57 / 62 / 61개 |

릭 자리가 되려면 여러 조건을 모두 통과해야 했다.

| 조건(v0.65) | 놓치던 자리 | v0.66.4 |
|---|---|---|
| 한 마디 = 한 코드, 그 코드가 그 마디에서 시작 | 두 박씩 바뀌는 Ⅱ–Ⅴ(리듬 체인지, 턴어라운드), 두 마디짜리 코드의 뒷마디 | 짧은 Ⅱ–Ⅴ 전용 릭 14개, 뒷마디 허용 |
| Ⅴ7 → Ⅰ 릭만 있음 | Ⅱm7 마디, Ⅱø 마디 | Ⅱ → Ⅴ 릭 14개 |
| 착지 코드는 메이저·마이너만 | Ⅴ7 → Ⅰ7(블루스 10 → 11마디) — 재즈 블루스에서 0회 | 7코드 착지 허용 |
| 프레이즈가 그 마디 앞에서 시작돼 있어야 | 프레이즈 첫 마디 | 첫 박·첫 엇박에서 시작하는 프레이즈 허용 |
| 4도 진행인데 맞는 릭이 없으면 건너뜀 | ⅰ → ⅳ, Ⅰ → Ⅳ | 코드 릭으로 대신 |
| 뽑힌 릭이 음역·도약에 안 맞으면 버림 | 뽑힌 것의 28% | 리듬이 같은 다른 릭으로 바꿔 놓음(13%로 감소) |
| 4/4 전용 | 왈츠 | 3/4 릭 15개 |

그대로 둔 조건: 노래 프레이즈(긴 음 위주), 블루스 프레이즈, 「8분 라인」·「한 음 리듬」 같은 장치가 걸린 마디, 두 프레이즈가 만나는 마디에는 릭을 넣지 않는다. 전체 마디의 절반쯤이 여기에 해당한다. 릭이 그 프레이즈의 성격을 깨기 때문에 일부러 남겼다.

## 3. 재즈 릭 어휘의 지도

Jerry Coker의 교재 *Elements of the Jazz Language*는 즉흥 어휘를 코드 따라가기, 숫자 패턴, 7→3 해결, 3→♭9, 비밥 스케일, 비밥 릭, 화성 일반화, 인클로저, 시퀀스, CESH, 인용 같은 요소로 나눈다. Bert Ligon의 *Connecting Chords with Linear Harmony*는 거장들의 선율 수백 개를 조사해 Ⅱ–Ⅴ를 잇는 뼈대를 세 가지(3-2-1-7 → 3, 5-3-1-7 → 3, 1-3-5-7 → 3)로 정리한다. David Baker가 이름 붙인 비밥 스케일은 경과음 하나를 더해, 코드톤에서 시작하면 코드톤이 계속 박에 떨어지게 한 것이다. 이 분류에 엔진을 대 보면 다음과 같다.

| 요소 | v0.65 | v0.66.4 |
|---|---|---|
| 코드 따라가기(아르페지오) | 4음 셀(교본 16 · 실측 141) | 한 마디 릭·코드 릭으로 확장 |
| 숫자 패턴(1-2-3-5 등) | 셀 3개 | 릭 `dg1` `ii2` `ch1` `s4` 등 |
| 7→3 해결(뼈대 세 가지) | 코드를 건너는 셀 1개(1-♭3-5-♭7 → 3) | 세 뼈대 모두: 릭의 끝맺음 대부분 + 건너는 셀 11개 |
| 3→♭9 아르페지오 | 셀 3개 | 릭 `bb3` `bb4` `hm2` `hm3` `hm6` `s2b` `m2` 등 |
| 비밥 스케일 | 4음 셀 2개 | 한 마디 릭 `bb1` `bb2` `gt2` `ii6`, 메이저 비밥 셀 |
| 인클로저 | 일반 장치(목표음 앞 두 음) | 릭 끝맺음(5-♭7 → 3, 5-3 → 1), 건너는 셀 2개 |
| 시퀀스 | 모티프 발전, 8분 라인 장치 | 릭 이어 붙이기(Ⅱ → Ⅴ → Ⅰ, Ⅲ–Ⅵ → Ⅱ–Ⅴ) |
| Ⅴ7의 색채(얼터드·트라이톤 대리·온음·디미니시) | 사용자 릭 3개 | 색채 릭 6개(단계 5), 셀 5개 |
| 마이너 Ⅱ–Ⅴ(로크리안, 하모닉 마이너) | 하프디미니시 셀 2개, Ⅴ → ⅰ 셀 1개 | 릭 22개(3/4 포함), 셀 6개 |
| 턴어라운드 | 없음 | Ⅰ → Ⅵ7 건너는 셀 2개, 짧은 Ⅱ–Ⅴ 릭 연결 |
| 리듬 어휘(셋잇단 꾸밈, 쉼표 뒤 시작, 긴 음 뒤 흐름) | 셋잇단 릭 3개 | 셋잇단이 든 릭 8개, 쉼표 뒤 시작 4개, 긴 음으로 끝나는 코드 릭 5개 |
| 블루스 어휘 | 블루스 프레이즈(별도 계획) | 그대로 — 릭은 블루스 프레이즈 밖에서만 |
| CESH(한 성부만 움직이기) | 없음 | `ii6`(1-7-♭7)에만 부분적으로 — 남은 과제 |
| 화성 일반화(Ⅱ–Ⅴ를 한 스케일로) | 없음 | 없음 — 남은 과제 |
| 인용, 곡 선율에서 온 릭 | 넣지 않음 | 넣지 않음(법적 선) |

## 4. 새 릭을 고른 기준

1. **박에는 코드톤.** 8분음표 여덟 개 가운데 1·2·3·4박 음이 코드톤이 되게 했다(색채 릭은 3·♭7 가이드톤을 박에 두고 색채음을 엇박에). 빌드 스크립트가 자동으로 센다.
2. **끝은 해결.** 마지막 음이 다음 코드의 3음(♭7에서 반음·온음 아래로), 1음, 5음으로 순차 진행하거나 위·아래에서 감싼다.
3. **관악으로 불 수 있게.** 릭 안의 도약은 완전5도 이하.
4. **리듬이 한 가지가 아니게.** 8분음표 여덟 개가 기본이지만, 긴 음 + 셋잇단 꾸밈으로 시작하는 릭, 첫 박을 쉬고 들어가는 릭, 긴 음으로 끝나는 코드 릭을 섞었다.
5. **단계에 맞게.** ♭9·얼터드·온음·디미니시는 그냥 7코드 위에서는 단계 5에서만, 코드 자체가 7♭9·7alt이거나 마이너로 해결할 때는 단계 3부터.
6. **사용자 릭이 묻히지 않게.** 새 릭의 무게는 0.45~0.6, 사용자 제공 릭은 1~3.

## 5. 실제 연주 자료와 대조

녹음을 옮겨 적을 수는 없으므로(법적 선) 두 가지로 확인했다.

- **교본의 뼈대**: 3절의 세 뼈대와 비밥 스케일, 3→♭9는 교재들이 실제 솔로에서 뽑아 정리한 공식이다.
- **WJD 실측 셀**: 엔진에는 Weimar Jazz Database에서 4명 이상의 연주자에게 공통으로 나온 4음 음형 141개가 들어 있다. 새 릭을 박에서 시작하는 4음 조각으로 잘라 이 목록과 맞춰 보면 266개 중 66개(25%)가 정확히 일치하고, 80개 릭 가운데 44개가 일치하는 조각을 하나 이상 가진다. 많이 겹친 것은 3-5-♭7-♭9, 3-♭9-1-♭7, 3-5-♭7-9, 1-♭3-5-♭7, ♭3-2-1-♭7, 1-7-♭7-6이다. 새 4음 셀 가운데 2개는 실측 셀과 완전히 같아서 뺐다.

## 6. 릭이 서로 이어지는 방식

- **두 마디 릭**: Ⅱ 마디 릭이 Ⅴ의 3음(또는 5음·1음)에 착지하면, 바로 그 음에서 시작하는 Ⅴ 마디 릭을 이어 붙인다. 릭을 통째로 외운 것이 아니라 반 토막씩 조합하므로 가짓수가 곱으로 늘어난다. 예(시험 진행, 단계 3): `Dø: C B♭ A♭ G F E♭ D C | G7♭9: B D F A♭ G F E♭ D | Cm7: C`
- **짧은 Ⅱ–Ⅴ 연쇄**: `Em7 A7 | Dm7 G7 | C`에서 첫 마디 릭이 Dm7의 ♭3음에 착지하면 ♭3음에서 시작하는 다음 릭이 이어진다.
- 프레이즈 구조 때문에 이어 붙일 수 있는 자리는 많지 않다(336코러스에 10~12번). 그런 자리는 릭 확률을 1.6배로 올려 두었다.
- 이어 붙이는 경우가 아니면 릭을 두 마디 연달아 넣지 않는다.

## 8. 남은 한계

- 장치가 걸린 마디에 릭을 넣지 않으므로, 「8분 라인」 장치가 길게 이어지는 곳은 여전히 규칙으로 만든 선율이다.
- 릭 변형이 없다: 박 자리 옮기기, 끝맺음만 바꾸기, 앞부분만 쓰기. 지금은 조합과 옥타브 선택뿐이다.
- 16분음표(더블 타임) 릭은 16분음표 지원 뒤에 넣을 수 있다. 발라드에서 릭이 적은 까닭이기도 하다.
- 5/4 릭, CESH, 화성 일반화는 없다.
- 기존 셀 이름 하나가 실제 음과 다르다: `Ⅴ: 5-4-3-2 → Ⅰ의 1음`은 Ⅴ의 뿌리(= Ⅰ의 5음)에 착지한다. 「선율 다듬기」를 껐을 때 v0.65와 같아야 해서 손대지 않았다.
- 릭 이름은 악보의 마디 설명에 `릭: …`으로 나온다. 이름이 길다고 느끼시면 줄일 수 있다.

## 10. 전체 목록

릭은 C조 예시(Dm7–G7–C, Dø–G7♭9–Cm)로 적었다. 숫자는 옥타브, 괄호는 셋잇단, → 뒤는 다음 마디 첫 박의 착지음, `|`는 코드가 바뀌는 자리다. 직접 쳐 보고 어색한 것은 기호만 알려 주시면 빼거나 고친다.
