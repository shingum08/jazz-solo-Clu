(우리끼리 테스트 전용 · GitHub에 올리지 않는 파일)

━━ 이 폴더에 든 것 ━━
index.html            앱 본체(설치·오프라인·업데이트 알림 켜짐)
manifest.webmanifest  앱 이름·아이콘 정보
sw.js                 오프라인·업데이트 담당(서비스 워커)
icons/                앱 아이콘(임시)

━━ 1. 먼저 알아 둘 것 ━━
· 홈 화면 "앱"으로 설치하려면 이 폴더가 https 주소에 올라가 있어야 합니다(브라우저 규칙).
  index.html을 파일로 그냥 열면 악보 생성·재생은 되지만 설치·오프라인은 안 됩니다.
· 주소를 아는 사람은 누구나 열 수 있으니, 주소는 테스트하는 사람끼리만 공유하세요.

━━ 2. https 주소에 올리는 방법(택1) ━━
A. Netlify Drop — 가장 간단
   https://app.netlify.com/drop 에 이 폴더를 통째로 끌어다 놓기 → 임의의 https 주소가 생김.
   ※ 로그인 없이 올리면 일정 시간 뒤 사라질 수 있음 — 계정을 만들어 사이트를 '보관(claim)'하세요. (조건은 확인 필요)
B. Cloudflare Pages — 무료 계정
   대시보드 → Workers & Pages → Pages → "Upload assets"(직접 업로드)로 이 폴더 올리기. (메뉴 이름은 확인 필요)

━━ 3. 휴대폰에 설치 ━━
아이폰·아이패드: 사파리로 주소 열기 → 공유 버튼(네모+위 화살표) → 「홈 화면에 추가」
안드로이드: 크롬으로 주소 열기 → 화면 위 「📲 앱으로 설치」 또는 메뉴(⋮) → 「앱 설치」
PC(크롬·엣지): 주소창 오른쪽 설치 아이콘 또는 「📲 앱으로 설치」

━━ 4. 업데이트 ━━
· 새 버전 zip을 받으면 같은 사이트에 폴더를 다시 올리세요(덮어쓰기).
· 설치된 앱은 열 때(또는 30분마다) 새 버전을 확인하고, 화면 아래에
  「🔄 새 버전이 준비됐어요 — 지금 업데이트 / 나중에」를 띄웁니다. 「지금 업데이트」를 누르면 새로고침되며 바뀝니다.

━━ 5. 아이폰 소리 확인 부탁 ━━
· 무음 스위치를 켠 상태 / 끈 상태 둘 다, 사파리와 홈 화면 앱 둘 다 재생해 보고 결과를 알려 주세요.
· 소리가 안 나면 앱의 「버그 리포트」를 보내 주세요(오디오 상태가 함께 적힙니다).

━━ 6. 저장한 솔로 ━━
· 아이폰은 사파리와 홈 화면 앱의 저장 공간이 따로입니다. 옮길 때는 「⬇ 백업 파일 내보내기 → ⬆ 백업 불러오기」.
